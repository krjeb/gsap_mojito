# Mojito Awwwards Website

A cinematic cocktail-bar landing page inspired by Awwwards-caliber design, built with React, GSAP, 
and Tailwind CSS — featuring scroll-synced video playback, SplitText reveal animations, parallax 
scrolling, and a custom animated carousel across navbar, hero, cocktails, about, art, and menu sections.

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Animation:** GSAP, @gsap/react, ScrollTrigger, SplitText
